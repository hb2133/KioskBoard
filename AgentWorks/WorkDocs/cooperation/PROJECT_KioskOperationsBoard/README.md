# 키오스크 행사 운영 보드 MVP

## Summary
- Notion에서 관리하던 키오스크 행사 일정, 운영 상태, 계약, 납품, 정산 정보를 Electron 앱으로 통합한다.

## Background
- 운영 담당자가 전체 현황, 월간 일정, 완료 행사 정산 상태를 한눈에 보기 어렵다.
- 행사 상태를 날짜에 맞춰 수동으로 변경해야 하는 불편이 있다.

## Scope
- 날짜 기반 예정·진행·완료 자동 계산
- 전체내역, 캘린더, 완료내역 보기
- 행사 등록, 수정, 삭제 및 로컬 저장
