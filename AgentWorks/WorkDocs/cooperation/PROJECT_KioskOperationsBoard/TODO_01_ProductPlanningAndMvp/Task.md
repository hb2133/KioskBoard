# Task

## Context
- Notion 기반 키오스크 행사 관리 흐름을 로컬 Electron 앱으로 전환한다.

## Current Understanding
- 전체내역·캘린더·완료내역은 별도 BasePanel이 아니라 동일 데이터의 보기 상태다.
- 운영 상태는 저장하지 않고 행사 시작일·종료일과 오늘 날짜로 계산한다.
- 첫 버전은 별도 서버 없이 PC 로컬 저장소를 사용한다.

## Observed Issues
- 기존 Electron 골격만 있으며 실제 Panel과 데이터 계층은 아직 없다.

## Decision Notes
- 정산 정보의 완결성을 위해 기존 완료내역에 없던 행사명과 잔금 납부 여부를 공통 행사 레코드에 포함한다.
- 설치시간은 날짜가 바뀌는 행사도 표현하도록 `datetime-local` 값으로 관리한다.
- 설치 일시가 행사 시작일보다 이르면 캘린더의 기존 행사 막대를 설치 시각부터 시작해 행사 종료일까지 연속해서 표시한다.
- 회수 일시가 있으면 캘린더 행사 막대의 종료 위치를 회수 날짜와 분 단위 시각에 맞춘다.
- 보유 키오스크 목록은 행사 기록과 분리된 로컬 저장소에서 관리한다.
- 행사에는 수동 대수·업체명 대신 설정에 등록된 보유 키오스크 ID 목록을 다중 선택해 연결한다.
- 키오스크 배정 가능 여부는 설치 시각부터 회수 시각까지의 점유 구간과 기존 행사 배정을 비교해 결정한다.

## Fix Notes
- planning Brief와 Panel별 설계를 작성했다.
- `OperationsBasePanel`에 전체내역, 월간 캘린더, 완료내역을 구현했다.
- 행사 등록·수정과 삭제 확인을 LayeredPanel로 구현했다.
- 행사 정보는 로컬 저장소에 영속화하고 운영 상태는 날짜로 계산한다.
- localization 문자열과 전역 디자인 토큰을 분리했다.
- 완료/미완료 칩의 너비를 고정해 토글 시 표 레이아웃이 변하지 않도록 했다.
- 설치 시각을 하루 중 분 단위 비율로 계산해 기존 행사 막대의 시작 위치에 반영하고 12시간제 표기의 시 앞자리 0을 제거했다.
- 행사 등록·수정과 전체내역에 회수 일시를 추가하고 기존 저장 데이터에는 빈 회수 일시를 자동 보정한다.
- 설정 LayeredPanel에서 보유 키오스크 등록, 중복 방지, 목록 확인, 삭제를 지원한다.
- 행사 입력의 키오스크 업체명과 수동 대수 입력을 제거하고 보유 키오스크 다중 선택 UI 및 자동 수량 표시로 교체했다.
- 일정이 겹치는 키오스크는 선택 불가로 표시하고 클릭 시 충돌 행사 안내, 팝업 흔들림, 붉은색 복귀 효과를 제공한다.
- 회사명·행사명·운용 키오스크 표시 폭을 제한하고 초과 문자열을 말줄임 처리했으며 충돌 팝업 흔들림 강도를 낮췄다.
- 전체내역 표를 패널 폭에 맞는 고정 레이아웃으로 바꾸고 회사명·운용 키오스크 열이 남은 폭을 유동 배분받도록 해 하단 가로 스크롤을 제거했다.
- 운용 키오스크의 문자열 선제 절단을 제거해 실제 열 너비에만 반응하는 말줄임으로 바꾸고 행사 일정 열의 위치와 내부 중앙선을 보정했다.
- 전체내역과 완료내역은 최초 5건만 표시하고 표 하단의 `더보기 +5`로 5건씩 확장하도록 구성했다.
- 캘린더 행사 막대를 클릭하면 일정, 배정 장비, 설치·회수, 계약·납부, 메모를 확인하는 읽기 전용 상세 LayeredPanel을 연다.
