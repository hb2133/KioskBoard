# Task

## Context
- GitHub README 상단에 웹 접속 링크를 배치하고 기존 스크린샷을 최신 UI로 교체한다.

## Current Understanding
- README 스크린샷은 전체내역 표기와 이전 데이터를 보여줘 현재 진행내역, 공휴일, 추가 행사 필드를 반영하지 못한다.

## Observed Issues
- 런타임에서 확인된 현상이나 새로 발견된 문제를 적는다.

## Decision Notes
- 방향이 바뀐 이유와 폐기한 가설을 적는다.

## Implementation Notes
- README 제목 바로 아래에 `https://kioskboard.vercel.app` 접속 링크를 추가했다.
- 주요 기능과 화면 설명에 진행내역, 콘텐츠·담당자, 주말·공휴일 표시를 반영했다.
- 진행내역, 행사 등록, 키오스크 설정, 캘린더, 행사 상세, 완료내역, 라이트 모드 7개 이미지를 1296x808 최신 실행본으로 교체했다.

## Result
- 모든 이미지의 해상도와 민감 정보 미노출을 확인했다.
